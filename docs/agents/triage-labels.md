# Triage Labels

Gunakan lima label berikut untuk menunjukkan keadaan issue.

| Label | Arti | Kapan digunakan |
| --- | --- | --- |
| `needs-triage` | Belum dievaluasi | Issue baru masuk dan perlu ditinjau maintainer |
| `needs-info` | Informasi belum lengkap | Pekerjaan menunggu jawaban atau detail tambahan dari pelapor |
| `ready-for-agent` | Siap dikerjakan agent | Requirement, batasan, dan acceptance criteria sudah jelas |
| `ready-for-human` | Membutuhkan manusia | Memerlukan keputusan, akses, kredensial, atau tindakan manual |
| `wontfix` | Tidak akan dikerjakan | Sudah diputuskan untuk tidak menindaklanjuti issue |

Jika sebuah skill menyebut salah satu role triage, gunakan label yang sama
seperti tabel di atas.
